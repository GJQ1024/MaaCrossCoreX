## 1. 区域定位口径（2026-11-04 定稿）

章节 07 的区域**不是列表**，而是一整幅**可平移的 2D 画布**，且**会记住上次平移位置**：进图后的视口偏移取决于上一次离开时停在哪。因此定位分两步，两条都必须遵守：

1. **边界锚定**：进图后反复把视口往左上推，每次滑动后抓帧算感知哈希（16×9 灰度均值哈希；**不用整帧 md5**，地图上的粒子/水流一直在动），**相邻两帧 hash 相同即认为已抵边界**，连续 2 帧相同才判定稳定。安全上限 8 次；到上限仍未稳定只记日志、继续往下走，**不许死循环**。锚定结果（滑动次数 / 稳定帧数 / 耗时 / hash）记在 `_SESSION["anchor"]`。
   - **实机要点**：斜向拖拽**不会移动画布**，一次锚定步必须拆成「先横（450,400→1150,400，视口→左）再纵（780,150→780,600，视口→上）」两次拖拽。2026-11-04 实测：4 步、16.0s、第 4 步 hash 未变化收敛。
   - **反向验证（必须有）**：hash 稳定只说明"拖不动"，拖不动也可能是起点压在卡片/浮层上被吞。所以每个边界稳定后**反向挪一步**（左边界往回=向右、上边界往回=向下），画面必须真的变化才算"确实在边界"；变了再拖回角落。反向也不动时依次换标准反向/备用反向/第三滑动线共 3 种手段，并把"试了几种"写进日志；3 种全失败即 `手势被吞，无法锚定`，直接失败，**禁止带着不确定偏移继续扫**。
   - 抓帧前必须排除转场帧：黑屏/淡入淡出的整帧接近纯色，其均值哈希**恒为全 0**，会把「第一滑」误判成已稳定。判据是平均亮度 ≥20 且采样网格灰度 std ≥8，并额外要求左下角能读到`普通`+`困难`两个模式页签。
2. **视口 OCR 找目标**：锚定左上角后按蛇形平移（右、右、下、左、左、下、右、右，最多 9 个视口），每个视口全屏 OCR，找**进度为 `0/x`** 的区域卡片（正则 `0\s*[/／]\s*\d+`，**不限定 x 的具体数字**）。每个候选打印 OCR 文本、box、置信度、关联到的区域名与全部点击候选。
   - **可点目标是「区域名」文字本身**（如「米德加尔特」）。**「地区N」那一行、`★x/y` 进度文字、红徽标都不响应**（同日实机对照验证：同一帧点「米德加尔特」开面板，点「核心元库」名称/徽标/双击全无反应）。
   - **进页判据**：点击后用**全屏 OCR** 找页面关键词 `章节选择 / 章节选 / 关卡7- / 进度`，命中任一即判进页，日志打印命中的文本+box+置信。**不再用固定 ROI**（离线帧实测标题 box=`[136,148,94,28]`，虽落在旧 ROI `[80,120,340,190]` 内，但换布局必漏）。这套判据只看**页面文字**；「区域锁死/未解锁」是另一套**视觉**判据（P-029 暗色徽标），两者不复用。
3. **找不到即失败**：扫完所有视口仍无**可进入**的 `0/x` → 动作返回 False → `主线刷取_未找到可刷区域_失败`，**不允许沿 `刷取完成` 收尾报成功**（洗白口径见 `docs/问题登记.md` P-026）。
4. **页签**：进图后先按配置选模式（`主线刷取_选择模式`，`select_mode`）：按文字框平均亮度复核选中态，已是目标**不点击**，不是才点，点后 0.6s 复核，最多 2 次仍不成立即失败；锚定后再复核一次仍为目标模式。**不盲点页签**（切模式会重置画布偏移，会把刚锚好的位置废掉）。

已删除的旧写法（禁止回潮）：`主线刷取_区域列表上滑`（固定上滑一次）、`主线刷取_区域再上滑`（只向上补 2 次）、`主线刷取_点击阻隔地带`（固定 ROI `[200,400,260,95]`）、`主线刷取_点击米德加尔特`（固定 ROI `[1000,400,280,95]`）、`主线刷取_区域分派`、`主线刷取_未找到关卡_正常完成`。
